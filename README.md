# 掲載URL収集ツール

## 起動

Python 3.10以上で以下を実行します。

```bash
pip install -r requirements.txt
streamlit run app.py
```

ブラウザで開いた画面からURL一覧のxlsx/csvをアップロードし、URL列と検索条件を設定してください。

## 検索API

Brave Search APIキーは任意です。未設定の場合、robots.txt、サイトマップとサイト内リンクを利用します。APIの利用料金・提供条件は契約前に確認してください。Google検索と同一の検索結果は保証されません。

## 注意

- 商品名判定はページの取得HTMLの本文テキストへの部分一致です。JavaScript描画後の文字は対象外です。
- 送客リンク判定はリンクURLの部分一致です。ASP中継・リダイレクトの最終遷移先は解析しません。
- robots.txtを取得できないサイトは安全側でスキップします。取得ページ数の上限があるため網羅性は保証されません。
- サイトマップは候補収集に使用しますが、巡回対象ページ数に上限があります。
- 「新規ドメインのみ」は前回の結果ファイルが必要で、検索条件が一致する完了ドメインだけをスキップします。
- アプリの処理中断時は途中結果が保存されません。長期運用ではSQLite等で逐次保存する改良を推奨します。
- サイトへのアクセス許可、利用条件、社内セキュリティ規定を確認してください。
- 外部の任意ドメインへのアクセスを行うため、社内ネットワークへの配置時はネットワーク側の送信制限も推奨します。
